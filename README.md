# 💖 HandMadeHearts

HandMadeHearts is a simple e-commerce web application designed to showcase and sell beautiful handmade products made with love and creativity. This is a personal project built as part of my learning journey in Java and web development.


## ✨ Features

- 🛍️ Browse a catalog of handmade items
- 📝 Add products manually (admin-side)
- 🧾 Basic order/request placement (work in progress)
- 🖥️ Dynamic HTML pages (JSP/Servlet-based)
- 🛠️ Java + JDBC + MySQL backend 


## 🧑‍💻 Tech Stack

| Layer       | Technology Used             |
|-------------|-----------------------------|
| Frontend    | HTML, CSS, Bootstrap        |
| Backend     | Java, Servlets, JSP         |
| Database    | MySQL (JDBC connection)     |
| IDE         | Eclipse IDE                 |
